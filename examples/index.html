stipple-gl

Examples

One finished scene each, no control panel. Every file is standalone: a script tag, a few lines of setup, and nothing to build. Read the source — that is the point of them.

  • container.html mode: 'container'

    A field bounded by a card instead of the viewport, with the layout rule that makes it work.

  • positioned.html fitShapeToElement

    The shape parked in a slot on the right, following the element as the window resizes.

  • scroll-snap.html createScrollMorph

    A shape per section, declared in the markup and cross-faded as you scroll.

  • mobile.html responsiveCount · container queries

    A portrait layout that spends fewer particles on small screens, and re-budgets on rotate.

These load ../dist/stipple.global.js, so run pnpm build first. Serve the repo root with pnpm examples and open /examples/.
